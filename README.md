## 👨‍💻 About Me

I'm an engineering student who builds **AI-powered products end to end**, from the model and the agent pipeline to the API and the UI.

- 🤖 Designing **multi-agent LLM systems** with LangGraph, RAG and vector search
- 🧠 Exploring **deep learning and reinforcement learning**, from a GPT-style transformer built from scratch to quadcopter control
- 🌐 Shipping **full-stack apps** with React, FastAPI and Node.js
- ⚙️ Automating workflows with **n8n** and building AI dev tooling
- 🌱 Always learning: currently going deeper into LLM optimisation and production ML systems
